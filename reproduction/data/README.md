The hardware data below is collected once on the
IQM Euro-Q-Exa (`EQE1`) machine and committed here (it cannot be regenerated
without machine access).

## Files

- `qexa_hardware.csv` — aggregated Euro-Q-Exa hardware point (genuine/garbage
  `E(λ)`, Richardson estimate, negativity) used in the horoscope-sweep figure.
- `horoscope_circuits.csv`, `horoscope_shots.csv`, `horoscope_spectrum.csv`,
  `horoscope_sweep.csv` — cached outputs of the simulator sweep
  (`scripts/horoscope_mechanism.py`); regenerated by `make repro`.
- `eqe_day/` — per-job raw (`*_raw.csv`, full per-shot counts) and aggregated
  (`*_summary.{csv,json}`) hardware data for the jobs used in the paper
  (`j4`, `j6`, `j8`, `j9`, `j11`, `j12`, `j13`, `j14`), plus `selected_layout.json`
  and `regime_choice.json` (chain and TC-config provenance).
- `logs/` — run logs of the hardware sessions (`hardware_experiments.log`,
  `horoscope_qexa.log`) for drift/parameter auditing without machine access.

The scripts that produced the hardware data live in `../hardware/`.
